# Trade ERP — запуск онлайн через Render

Эта версия подготовлена для запуска через браузер без Docker и без установки Python на ваш компьютер.

## Что получится

После публикации Render выдаст адрес вида:

`https://trade-erp-xxxx.onrender.com`

Вы открываете его в Chrome/Edge и работаете.

## Вариант для нормальной работы

Файл `render.yaml` создаёт:
- веб-приложение Trade ERP;
- постоянную PostgreSQL-базу данных;
- HTTPS;
- автоматический секрет для сессий.

Веб-сервис оставлен на бесплатном тарифе для простоты старта, поэтому после периода бездействия первый вход может открываться дольше обычного. База в `render.yaml` настроена на постоянный платный минимальный PostgreSQL, чтобы рабочие данные не исчезли через 30 дней.

## Что сделать

1. Создайте аккаунт на GitHub.
2. Создайте новый пустой репозиторий, например `trade-erp`.
3. Распакуйте этот ZIP на компьютере.
4. Загрузите в корень репозитория все файлы из архива. В корне GitHub должны быть видны `main.py`, `requirements.txt` и `render.yaml`.
5. Создайте аккаунт на Render и подключите GitHub.
6. В Render откройте **New → Blueprint**.
7. Выберите репозиторий `trade-erp`. Render автоматически найдёт `render.yaml`.
8. При создании Render попросит значение `ERP_ADMIN_PASSWORD`. Введите ваш собственный сложный пароль и сохраните его.
9. Нажмите **Apply / Deploy**.
10. Дождитесь статуса `Live` и откройте выданный адрес `*.onrender.com`.

Вход:
- логин: `admin`
- пароль: тот, который вы ввели в `ERP_ADMIN_PASSWORD`.

## Важно про тестовый бесплатный вариант

В архиве есть `render-free-test.yaml`. Его можно использовать только для проверки. Бесплатная база Render действует 30 дней, после чего её нужно перевести на платный тариф, иначе рабочие данные будут недоступны и позже удалены.

## Локальный запуск

Для локальной проверки по-прежнему поддерживается SQLite. Если `DATABASE_URL` не задан, приложение создаёт локальный `erp.db`.
