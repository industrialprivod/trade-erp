# Trade ERP Online

Онлайн-версия MVP системы управления торговлей.

## Рекомендуемый запуск

Откройте `ONLINE_START_RU.md` и выполните пошаговую инструкцию для Render.

## Что работает

- авторизация;
- контрагенты: клиенты / поставщики;
- номенклатура;
- RFQ / заявки;
- позиции RFQ;
- закупочная цена RMB/USD/EUR/RUB;
- курс валюты;
- логистика, пошлина и прочие расходы;
- расчёт полной себестоимости;
- цена продажи, прибыль и маржа;
- статусы RFQ;
- заказы продажи и закупки;
- статусы заказа и оплаты;
- директорский дашборд;
- PostgreSQL в облаке и SQLite для локального теста.

## Администратор

Логин: `admin`.
Пароль для онлайн-развёртывания задаётся в Render через `ERP_ADMIN_PASSWORD` при первом создании Blueprint.

Не используйте тестовый пароль `admin123` в интернете.
